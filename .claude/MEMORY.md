# Repo Memory (index)

Durable facts, decisions, and how-tos that are worth persisting **in this repo** (checked in,
shared with anyone who clones it) rather than only in the AI tool's private cross-session memory.
Each entry below is a one-line pointer into `.claude/memory/`.

This is separate from an AI tool's own private memory system (e.g. Claude Code's per-user memory
directory outside the repo) — that one is for durable facts about how *you* (the user) want repos
worked on in general. This index is for facts about *this specific repo* that any contributor or
agent working on it should be able to see.
