## What changed and why

PLAN Phase 1 item 6. A streamer can now go from a clone to a working source using only this
README. The parameter documentation is taken from `obs-page.js` itself, not from the plan. In
particular:

- `cycle=0` holds the first preset.
- `blend` clamps to 0–10. `cycle` and `fps` fall back to their defaults on negative values.
- `audio` keywords are case-insensitive.
- The `+`/space equivalence in matching applies to both presets and labels.

Deviation from the delegation text: the server command is
`python3 -m http.server 8080 --bind 127.0.0.1 --directory browser-source`. Without `--bind`,
Python 3 listens on every interface and would serve the presets to the LAN, which goes against the
core's "local serving only" terms. The URL is unchanged (`http://localhost:8080/`), and
`curl http://localhost:8080/` works with this bind.

OBS UI strings were checked against the installed OBS 33.0.3 locale files without launching OBS.
OBS 33's "Add Source" dialog strings ("Create New", "Add existing") differ from the classic
"+ → Browser → Add Existing" menu, so the README words those steps generically. Statements that
could not be checked are marked untested in the README: Windows, Linux, the loopback driver UI,
the remote-debugging steps and hidden-source pausing in OBS.
