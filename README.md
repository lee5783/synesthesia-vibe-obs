# SynesthesiaVibe for OBS

OBS Studio integration for [SynesthesiaVibe](https://github.com/lee5783/synesthesia-vibe), a
MilkDrop-preset music visualizer: a Browser Source page first, then a native OBS source plugin
that reacts to OBS audio.

Work in progress — nothing is released yet. See [`PLAN.md`](PLAN.md) for the phases, open
decisions and risks.
